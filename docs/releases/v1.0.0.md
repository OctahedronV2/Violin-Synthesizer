The first release of **Octavio**, a physically modelled violin for your DAW. It was called Violin Synthesizer during development.

## Download

| Platform | File | Install to |
|---|---|---|
| Windows | `Octavio-VST3-Windows.zip` | `C:\Program Files\Common Files\VST3\` |
| macOS (Apple silicon and Intel) | `Octavio-VST3-macOS.zip`, `Octavio-AU-macOS.zip` | `~/Library/Audio/Plug-Ins/VST3/` or `.../Components/` |
| Linux | `Octavio-VST3-Linux.zip` | `~/.vst3/` |

Each platform also has a Standalone app. Unzip, copy, then rescan plugins in your DAW and add **Octavio** (vendor OctahedronV2). The macOS builds are not notarised; see the README for the one-line `xattr` command that lets them load.

## What's in it

- Four physically modelled bowed strings sharing one bow, on measured violin bodies, with double stops, legato, string crossings and sympathetic resonance.
- A player that keeps the bow clean on every note, with an **Imperfection** knob to add a real player's scratch and wobble back.
- Ten articulations, including a pizzicato plucked by a fingertip and fitted to recorded violin notes, selectable from the editor or by keyswitch.
- Expressive control: velocity, mod wheel, expression, bow position, pitch bend and MPE; every control can be automated.
- 27 level-matched factory presets and your own presets.
- Tested with pluginval (strictness 10) and Steinberg's VST3 validator, and made for FL Studio, Reaper and Ableton Live.

## Coming from Violin Synthesizer

**Delete the old `Violin Synthesizer.vst3` (and `.component` on macOS) before installing Octavio.** Octavio keeps the same plugin IDs, so hosts would otherwise see two plugins claiming to be the same one. Keeping the IDs means projects saved with Violin Synthesizer should open with Octavio in its place. Your saved presets are copied from `Documents/OctahedronV2/Violin Synthesizer/Presets` to `Documents/OctahedronV2/Octavio/Presets` the first time Octavio runs.
