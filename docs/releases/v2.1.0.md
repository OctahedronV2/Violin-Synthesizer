**Octavio 2.1** adds a real bridge, a more musical player, and pizzicato and harmonics.

## A real bridge

- **The bridge is fitted to a measured violin** (the CNSM Stoppani's bridge admittance, 76 modes), and all four strings sit on it. Each note now gets its own body colour, and releases ring more like a real violin.
- **Sympathetic** (Tone tab): how freely the open strings you aren't playing ring along.
- **Wolf**: a wolf note at the body's strongest resonance, near C5. Those notes go rough and unsteady at high settings. Off by default.
- **Hold**: the chin and hand damping the violin's low resonances. 0 lets the violin hang free, which sounds boomier.

## A more musical player

- **Phrasing**: the player shapes phrases with an arch, swells on long notes and stress in runs. It shapes most when every note has the same velocity, so a keyboard at a constant velocity still sounds musical. **Phrasing** sets how much (Articulation tab).
- **Deeper bow changes and a slightly slower, more varied vibrato**, wider on long and stressed notes.
- **Bow style** (Articulation tab): Auto, or Legato, Détaché, Staccato, Martelé or Spiccato for every note.
- **Plan fingering** (Studio mode, off by default): the player chooses strings and positions for the whole look-ahead, with shifts that land on the beat.
- **Curves as MIDI**: on the Curves tab, drag the player's curves out as a MIDI file (or click to save it to Documents/Octavio 2). Its CC lanes (CC1 dynamics, CC19 vibrato rate, CC26 vibrato width, CC74 contact point) take over from the player when played back in; CC121 hands them back. **Drawn curves** turns that off.

## Pizzicato and harmonics

- **Articulation** (Articulation tab, or keyswitches C1 to E1 at any Octave setting): Arco, Pizzicato, Bartók pizz, Left-hand pizz and Harmonics.
- **Pizzicato** is a real pluck of the string by a fingertip, harder and brighter as velocity rises.
- **Bartók pizz** snaps the string against the fingerboard.
- **Left-hand pizz** is softer, as when a left finger plucks an open string.
- **Harmonics** are played with a light finger on the string: natural harmonics where the note has a node, artificial harmonics otherwise.

Every new control can be automated. Projects from 2.0 open with the new bridge and player, so they sound a little different.

## Install

| Platform | File | Install to |
|---|---|---|
| Windows | `Octavio2-VST3-Windows.zip` | `C:\Program Files\Common Files\VST3\` |
| macOS (Apple silicon and Intel) | `Octavio2-VST3-macOS.zip`, `Octavio2-AU-macOS.zip` | `~/Library/Audio/Plug-Ins/VST3/` or `.../Components/` |
| Linux | `Octavio2-VST3-Linux.zip` | `~/.vst3/` |

**Updating from 2.0:** close your DAW, then unzip and copy `Octavio 2.vst3` over the old one. Standalone apps are in the `Octavio2-Standalone-*.zip` files. The macOS builds are not notarised; see the README for the one-line `xattr` command that lets them load.

Known limits: pizzicato starts about 20 ms late in Live mode (Studio mode is on time), Bartók pizz is a little dark, and harmonics are quieter than bowed notes. Very loud playing (velocity near 127) in the concert hall can peak above 0 dBFS; turn Volume down a few dB if you play that hard.
