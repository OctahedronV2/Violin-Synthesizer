A fix release for **Octavio** 1.0.

## Fixes

- **The computer keyboard keeps playing notes while you use the editor.** In FL Studio, clicking a control could take the keyboard away from the typing keyboard. Now clicking or dragging knobs, the bow pad, drop-downs, articulation buttons and the preset arrows never does. Only typing a value into the box under a knob takes the keyboard, and it goes back to your DAW when you press Enter or click anywhere else.
- **Every preset starts at Octave +1**, so a typing keyboard's lowest key plays C4. Projects you already saved keep their octave.
- **No more strings going silent.** With the bow near the bridge and a firm pressure (Bright Soloist, for one), a note on the G or A string could lock the string to the bow, so it moved with the hair and made no sound for as long as the note was held. The player now eases the bow the moment the string locks, as a violinist would, and the note speaks. Slow Swells, whose slow starts were caught by this too, is re-levelled.
- **Note names match your DAW.** FL Studio calls middle C "C5", Ableton Live, Cubase, Logic, Bitwig and Studio One call it "C3", and most others "C4". The keyboard, the string display and the keyswitch labels now use your host's names, so an A4 in FL Studio's piano roll shows as A4.
- **Notes outside the violin's range are silent.** Before, they all played the nearest note of the range. The range is G3 to G7 in standard names (G4 to G8 in FL Studio, G2 to G6 in Ableton Live) and applies after the Octave setting. The on-screen keyboard now shows the notes as they sound.

## Install or update

| Platform | File | Install to |
|---|---|---|
| Windows | `Octavio-VST3-Windows.zip` | `C:\Program Files\Common Files\VST3\` |
| macOS (Apple silicon and Intel) | `Octavio-VST3-macOS.zip`, `Octavio-AU-macOS.zip` | `~/Library/Audio/Plug-Ins/VST3/` or `.../Components/` |
| Linux | `Octavio-VST3-Linux.zip` | `~/.vst3/` |

**Updating from 1.0.0:** close your DAW, then unzip and copy `Octavio.vst3` over the old one (replace it when asked). Your projects and presets carry over, and there is no need to rescan.

**New install:** unzip, copy to the folder above, then rescan plugins in your DAW and add **Octavio** (vendor OctahedronV2). If you still have the pre-1.0 `Violin Synthesizer.vst3`, delete it first. The macOS builds are not notarised; see the README for the one-line `xattr` command that lets them load.

The keyboard fix is for Windows hosts. On macOS the editor behaves as in 1.0.0.
